# 《修仙模拟器：天命心火》 (Project: Cultivation & Heartfire)

> **类型标签**：纯文字与2D平面国风 / 放置修真 / 太吾绘卷式博弈 / 气运天命检定 / 亲铸神兵与真名印信 / 秘境搜打撤 (Extraction Roguelite)  
> **运行形态**：纯单文件/纯静态Web，手机端与电脑端双端自适应，双击 `index.html` 即可畅玩！

---

## 游戏核心设计理念

### 1. 还原经典古籍质感（高度呼应原截图）
* **视觉底色**：温润护眼的米黄宣纸纹理、柔和水墨细边框、宋体/楷体古籍排版。
* **生动微动效**：中央动态自转的2D Canvas水墨阴阳太极八卦盘，呼吸吐纳间有灵气聚拢与墨韵涟漪，点击浮现暴击飘字。
* **修真流水日志**：如实记载山间闭关、天地异象，以及触目惊心的**「同门弟子盗取我本命心火！」**恩怨情仇。

### 2. 百工手作与真名烙印（绝对纯手工）
* **无成品掉落**：世间没有现成的绝世神兵，全部源于道友亲采木石、洞府药园培育。
* **真名印信**：每一件锻造出来的装备都会烙上道友的道号真名与铸造年份，生成专属印信（例如：`道友「太虚散人」亲铸`）。
* **开炉气运判定**：铸造时取当时**【福缘】**测算天机，决定品阶跃迁（凡、灵、玄、宝、仙、神）与觉醒气运真言（如【福泽天眷】、【因果逆转】）。
* **装备损耗与修缮**：装备有耐久度，恶战磨损后需投入矿石在百炼炉中淬火修缮。

### 3. 多人对战与博弈（双模式齐备）
* **模式 1：昆仑论道台（太吾绘卷式灵气骰博弈）**：
  * 双方投掷 3 颗灵气骰（D6），根据点数大小、组合与装备词条决定出招威力，以道破法。
* **模式 2：太虚古墟·搜打撤（Extraction 杀人夺宝核心玩法）**：
  * **搜**：探索古遗迹，搜集奇珍矿石装入临时储物袋（撤离才能落袋）。
  * **打**：遭遇同门修士截杀，掷百面天道骰（D100）白热化争夺！
  * **博弈与夺取**：
    * **胜者**：搜刮物资，并有大概率**【杀人夺宝】直接缴获对方身上的亲铸神兵**，并抽取其本命心火！
    * **败者**：临时行囊洗劫一空，身上的极品装备面临**被夺走或受损震碎**的高危代价，心火被盗！
  * **撤**：寻找归返石阵引导撤离，安全带出全部战利品。

### 4. SQLite 持久化数据库、天道金榜与万宝楼交易行
* **底层数据库**：使用高性能零配置的 `xiuxian.db` (SQLite3)，存储全服修士档案、金榜天骄、法宝寄售交易账目。
* **天道金榜 (排行榜)**：
  * **战力金榜**：全服修士战力排行；
  * **气运天命榜**：全服大机缘、福缘气运排行；
  * 玩家每次境界突破、获得神兵都会实时同步至云端金榜。
* **万宝楼坊市 (交易行)**：
  * **买宝**：可使用挂机或秘境挣得的灵石，购买其他道友亲铸的绝品神兵；购买后原作者真名印信与因果流转记录完整继承！
  * **寄售**：玩家可把自己亲铸的法宝挂牌上架自定标价，其他修士买下后灵石自动入账！

## 快速游玩指南

1. **直接启动**：浏览器访问 **`http://localhost:8088/`** 即可畅玩；
2. **后端服务**：全栈服务已在后台运行 `python server.py`（提供 SQLite 数据库接口与金榜/交易行服务）；
3. **移动端适配**：直接用手机浏览器打开该局域网 IP，页面自动自适应手机比例，支持触屏点击吐纳；
4. **双重存档机制**：本地 `localStorage` + 服务端 SQLite 双重持久化同步。
